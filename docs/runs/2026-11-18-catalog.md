# P28 — спецификация каталога и отчёт о полноте

18 ноября 2026 года полный прогон `openmetadata-catalog_20261118-185907` на Linux-раннере iMac завершился с `JOB_ok`. Прошли Ruff и девять тестов на Python 3.11. В архиве сохранены сводка задания и оба журнала pytest. [Артефакты CI](catalog-ci.zip)

| Проверка | Результат |
|---|---|
| Выборка и отчёт, 6 тестов | Проверены границы выборки двух источников, неполный и полностью заполненный снимки, отклонение дубликата и обёртки страницы API |
| Клиент OpenMetadata 2.0.8.0, 3 теста | Штатный парсер принял две конфигурации. Модели запросов приняли две учебные группы, глоссарий и семь терминов. Ссылки из спецификации ведут к объявленным объектам, группам и терминам |
| Прямые зависимости | Вручную сверены с SQL исходных проектов. Для представления заказов указана одна связь, для трёх маркетинговых таблиц — пять |

На синтетическом снимке команда `python scripts/completeness.py examples/partial-tables.json` нашла 3 действующие карточки из 7. Описание заполнено у 2, ожидаемая команда назначена у 2, подтверждённый термин есть у 1. Полностью заполнена 1 карточка. Из остальных объектов 1 помечен удалённым и 3 отсутствуют в снимке. [Пример](../../examples/partial-tables.json) · [Спецификация](../../catalog.json)

До реализации отчёта три теста завершились ошибкой из-за отсутствия скрипта в прогоне `openmetadata-catalog_20261118-185645`. Для приёмки предстоит подтвердить связи и назначения в работающем каталоге, снять фактические показатели полноты и выполнить проверки качества данных. [План приёмки](../PLAN.md)
